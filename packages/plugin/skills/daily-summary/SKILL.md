# Daily Summary（每日笔记总结与待办梳理）

用于根据用户存储在本地 Daily Notes 中的真实记录，提炼工作日报、近期工作回顾或未完成待办清单。

## 执行步骤

1. **识别目标范围**：
   - 若用户询问「今天 / 今日总结」，调用 `daily_notes_get` 获取当日笔记。
   - 若用户询问「本周 / 最近 N 天 / 跨日进展」，调用 `daily_notes_list_range`（先设 `include_content: false` 快速了解概况，按需再读取正文）及 `daily_notes_get_open_todos`。
   - 若用户指定关键词、`#标签` 或工作区项目，调用 `daily_notes_search` 精确定位。

2. **结构化提炼输出**：
   - 严格依据工具返回的真实正文与待办状态进行总结，不虚构未记录事项。
   - 按清晰结构呈现：**今日/近期核心进展**、**已完成事项**、**待办与阻塞项（标注所属日期）**、**关键标签/关联项目**。

3. **只读默认边界**：
   - 默认仅在对话中输出总结，**不要擅自写回笔记**。
   - 仅当用户明确要求「把总结写入今日笔记」或「更新到日报小节」时，先确认最新 `revision` 后再调用 `daily_notes_append`（传入 `heading: "今日总结"` 等合适标题与 `summary`），并告知用户版本号与侧边栏一键撤销入口。
