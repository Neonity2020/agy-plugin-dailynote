# Daily Capture（一键记录到今日笔记）

用于将对话中的高价值上下文（设计决策、Bug 排查结论、命令行结果、新待办）沉淀到今日的 Daily Notes 中。

## 执行步骤

1. **先读今日笔记上下文**：
   - 调用 `daily_notes_get` 读取今日笔记现有内容与 `revision`，了解已有小节结构（如是否已有 `## 今日目标`、`## 排查记录`、`## 待办`），避免重复写入相同条目。

2. **精炼结构化 Markdown**：
   - 将对话结论提炼为简洁、信息密度高的 Markdown（使用 `- `、`- [ ] `、代码块或 `[[YYYY-MM-DD]]` 双链），可附带自然 `#标签`（如 `#排查`、`#架构`）。
   - 若当前对话处于明确工作区下，顺带传入 `workspace_uri` 与 `workspace_name` 关联当前项目。

3. **安全追加写入**：
   - 使用 `daily_notes_append`（而非 `daily_notes_update`）追加到合适 `heading` 或文档末尾，并提供简明的 `summary`（例如 `"记录接口排查结论"`）。
   - 若发生冲突或写入失败，向用户如实报告错误原因，不强行覆盖。

4. **清晰回执**：
   - 写入成功后明确告知用户：「已写入 `YYYY-MM-DD` 每日笔记（当前版本 `rev N`），若需要调整可在侧边栏点击一键撤销。」
