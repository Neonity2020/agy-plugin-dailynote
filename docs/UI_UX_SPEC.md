# Daily Notes（每日笔记）UI / UX 交互规范

## 1. 视觉风格与视口约束

### 1.1 视口适配目标
本插件主要运行在 Antigravity 辅助侧边栏（`SIDECAR_UI_ENTRYPOINT_AUX_PANE`）中：
- **标准窄侧边栏模式（核心态）**：`320px – 480px` 宽度，高度随宿主面板自适应。所有顶栏控件、日期日历、悬浮工具栏、表格与代码块必须在该宽度下零横向溢出、不遮挡编辑光标。
- **宽面板模式**：`>= 480px`（用户拖拽加宽侧边栏或独立浏览器开发调试时），正文区居中约束最大阅读宽度 `680px`，保留舒适留白。

### 1.2 原生融合与主题同步
遵循 Antigravity 侧边栏 UI 的低噪音、高可读性（Low-chrome）设计规范：
1. **样式变量继承**：在 `index.html` 头部引入 `<script src="/preload.js"></script>`，宿主自动把当前主题 Token 注入 `:root`（如 `--background`、`--foreground`、`--muted`、`--muted-foreground`、`--primary`、`--border`、`--font-family`、`--font-mono` 等），并提供本地调试兜底值。
2. **亮/暗模式感知**：使用与 Antigravity 内置面板一致的亮度探测逻辑，读取 `--background` 计算相对亮度并写入 `:root[data-theme="light" | "dark"]`，通过 `MutationObserver` 监听 `document.documentElement` 的 `style` 属性变化实时响应主题切换（包括代码块高亮、提示条底色与轻弹窗阴影）。
3. **字体与间距标尺**：
   - 间距严格使用 `4px` 倍数基准（`4 / 8 / 12 / 16 / 20 / 24px`）。
   - UI 控件文字 `11px – 13px`，编辑器正文 `14px`（行高 `1.65`），代码字体沿用 `--font-mono` `13px`。
   - 仅将 `--primary` 保留用于「今天」强调标识、主确认动作与键盘焦点环（Focus Ring）。

## 2. 整体信息架构与线框布局

在 `360px` 标准窄侧边栏中，页面采用「固定紧凑顶栏 + 可选上下文提示条 + 弹性主编辑区 + 极简底部状态栏」的纵向四段式结构：

│ 📁 未关联项目 · [+ 关联当前项目 sidelist]                 │ ← 项目上下文条 (可选/可收起)
├────────────────────────────────────────────────────────┤
│ 📋 昨日(11-24) 有 3 项未完成待办   [一键顺延] [忽略]      │ ← 昨日待办顺延条 (条件显示)

## 3. 核心界面模块规格

### 3.1 顶部导航栏（Header）
高度 `44px`，单行不折行（极窄 `320px` 下按钮间距收紧为 `4px`）：
- **返回按钮 `[←]`**：仅当用户通过 `[[YYYY-MM-DD]]` 双链或搜索跳转离开原始阅读日期、浏览历史栈非空时显示，点击回到上一个浏览日期。
- **日期切换组**：
  - `<`：前一天；`>`：后一天（支持切换到未来日期做计划，如明天）。
  - **日期标题按钮**（如 `11-25 周三` 或 `2026-11-25`，窄屏省略年份，非当年时展示完整年份）：点击展开/收起**折叠式迷你日历**。
  - **`今天` 胶囊按钮**：仅当当前不在本机「今天」时显示，点击一键跳回今日。
- **右侧功能图标组**（均有 `title` 悬停提示与快捷键标注）：
  1. **搜索 `🔍`**（`⌘K` / `Ctrl+K`）：打开搜索与标签/项目过滤抽屉。
  2. **AI 总结 `✨`**：触发「AI 总结今日」（详见 §5.1）。
  3. **源码切换 `</>`**（`⌘/` / `Ctrl+/`）：在所见即所得视图与纯 Markdown 源码视图之间切换。
  4. **更多菜单 `···`**：
     - 复制今日 Markdown
     - 导出为 `YYYY-MM-DD.md`
     - 导出包含 YAML Frontmatter 的 `.md`
     - 查看今日历史快照（`note_revisions` 列表抽屉）

### 3.2 上下文条与动态提示条（Contextual Banners）
所有提示条均采用轻量扁平卡片风格，避免过多堆叠；同时最多只显示直接相关的 1–2 条：
1. **项目关联条（默认 32px 单行）**：
   - 若今日已有已关联项目：显示项目胶囊列表（如 `📁 sidelist ×`）及 `关联其他`（若当前工作区尚未关联则显示 `+ sidelist`）。
   - 若今日尚无任何关联项目且当前存在打开的 Antigravity 工作区：显示低对比度提示 `+ 关联当前项目 (<workspaceName>)`。
   - 若处于无工作区的独立状态且今日无关联项目，则自动隐藏该条以节省垂直空间。
2. **昨日待办顺延条（条件出现）**：
   - **触发条件**：当前视图为「今天」、今日正文尚为空（`exists === false` 或 `content_md.trim() === ''`）、未执行过顺延且用户未在本机关闭该提示（`carry_over_dismissed === 0`），并且最近一篇前序笔记中存在 `>= 1` 条未勾选复选框（`- [ ]`）。
   - **展示文案**：`📌 <最近日期> 有 N 项未完成待办` + `[查看/一键顺延]` + `[忽略]`。
   - **点击「一键顺延」**：将前序未完成待办以标准任务清单格式插入今日顶部（若前序是多级子任务仅保留扁平或保留相对缩进），并记录幂等标记后自动收起提示条。
3. **跨零点轻提醒条（条件出现）**：
   - 当面板在开启状态下跨越本地 `00:00` 且用户正停留在原日期时，顶部展示：`🌙 新的一天 (YYYY-MM-DD) 已开始 [切换到今天] [留在当前页]`。
4. **外部更新 / 编辑冲突条**：
   - 见 §5.2 实时同步与冲突处理规范。

### 3.3 折叠式迷你日历抽屉（Mini Calendar Drawer）
点击顶栏日期标题后在顶栏下方平滑展开（覆层或向下推开正文区，可再次点击日期标题或按 `Esc` 收起）：
- **月份头部**：`< 上月`、`2026年11月`、`下月 >`、`回到本月`。
- **7 列周历网格**（周一至周日）：
  - **今日**：浅主色边框环（`--primary`）标识。
  - **当前正在查看的日期**：实心 `--primary` 背景反白高亮。
  - **有笔记的日期**：数字下方显示一个 `4px` 实心圆点；若当日存在未完成待办，圆点可轻微区别（空心环表示仍有未完成待办，实心点表示全部完成或无待办）。
  - **快捷筛选**：日历底部附带当前月份的活跃 `#标签` 与关联项目快捷过滤胶囊，选中后日历仅点亮命中的日期。

### 3.4 搜索与多维过滤面板（Search Overlay）
通过顶栏 `🔍` 或 `⌘K` 打开，覆盖编辑器区域（可随时 `Esc` 关闭）：
- **输入框**：即时输入防抖（`200ms`）检索中英文关键词；支持直接在输入框键入 `#标签` 自动识别为标签过滤。
- **过滤栏**：
  - 标签多选/单选胶囊（展示全库高频 `#标签`）。
  - 项目下拉筛选（全部项目 / 当前项目 / 已关联过的历史项目）。
  - 日期范围快捷切换（全部 / 近 7 天 / 近 30 天）。
- **结果列表**：
  - 按日期倒序（或相关度）展示命中记录：日期徽标 + 关联项目胶囊 + `<mark>` 高亮命中片段（2 行截断）。
  - 点击结果立即跳转到该日期并关闭搜索面板。

## 4. 所见即所得（WYSIWYG）编辑器交互规范

### 4.1 Markdown 快捷语法即时渲染
用户在编辑器行首或行内键入标准 Markdown 语法时实时转换：
- `# ` / `## ` / `### ` → 一级 / 二级 / 三级标题
- `- ` 或 `* ` → 无序列表；`1. ` → 有序列表
- `- [ ] ` 或 `[] ` → 可点击任务清单复选框；`- [x] ` → 已完成任务项
- `> ` → 引用块；`---` → 分割线
- ```` ``` ```` 或 ```` ```ts ```` + 回车/空格 → 语法高亮代码块
- 行内包裹：`**粗体**`、`*斜体*`、`~~删除线~~`、`` `行内代码` ``、`==高亮==`、`[文本](url)`
- **反悔机制**：刚触发块级转换时按一次 `Backspace` 或 `⌘Z` 撤销转换回纯字符。

### 4.2 选中悬浮工具栏（Bubble Menu）
选中非空文本时自动浮现在选区上方（窄屏自动左右边界夹紧 `8px` 防裁切）：
- 格式按钮：`B`（加粗）、`I`（斜体）、`S`（删除线）、`<>`（行内代码）、`🖍`（高亮）、`🔗`（编辑超链接）。
- 分割线 + **AI 快捷动作**：`💬 发送到对话`（将选中文本连同所在日期发往 Antigravity 当前对话）。
- 在代码块内部选中文本时隐藏普通富文本 Bubble Menu，避免误格式化代码。

### 4.3 斜杠插入菜单（Slash Command `/`）
在空行或段首输入 `/` 弹出紧致列表菜单（高度自适应，带小图标 + 中文名 + 快捷语法提示），支持输入拼音/英文过滤（如 `/todo`、`/code`、`/table`）及 `↑/↓/Enter/Esc` 键盘操作：
1. **任务清单**（`- [ ]`）
2. **一级标题 / 二级标题 / 三级标题**
3. **无序列表 / 有序列表**
4. **代码块**（```` ``` ````）
5. **引用块**（`>`）
6. **表格**（默认插入 `3列 x 3行` 含表头表格）
7. **插入图片**（唤起系统文件选择器）
8. **日期双链**（`[[` 自动切入日期选择）
9. **分割线**（`---`）

### 4.4 6 类 V1 扩展块精细交互

1. **任务清单（Task List）**：
   - 点击左侧复选框立即切换完成态，已完成项文本呈现淡化删除线样式，支持 `Tab` / `Shift+Tab` 嵌套缩进，空待办项按 `Enter` 自动退出任务列表。
2. **代码块（Code Block）**：
   - 右上角悬停/常驻轻量化操作栏：语言选择下拉（默认 Plain / 自动识别，常用语言 TS/JS/Python/Bash/SQL/JSON/YAML/Go/Rust 置顶）+ `复制` 按钮（复制成功显示 `✓`）。
   - 代码块内部 `Tab` 插入 2 空格、`Cmd+Enter` 跳出代码块到下方新段落。
3. **表格（Table）**：
   - 外层包裹 `overflow-x: auto` 滚动容器，防止多列表格把 320px 侧边栏撑出全局横向滚动条。
   - 光标停在单元格内时，表格上方或单元格左上角出现紧凑浮层按钮：`+行`、`+列`、`删行`、`删列`、`删表`。支持 `Tab` / `Shift+Tab` 在单元格间跳转。
4. **图片（Image）**：
   - **插入**：支持编辑器内直接 `Cmd+V` 粘贴剪贴板图片、从桌面/IDE 拖拽图片文件释放插入、或通过 `/` 菜单选择本地图片。
   - **上传态与落盘**：立即显示占位 Skeleton 并调用 `POST /api/attachments` 上传至本地 `attachments/`；成功后替换为 `/api/attachments/<id>` 真实图片；失败则显示错误重试卡片。
   - **展示与预览**：图片默认自适应容器宽度（`max-width: 100%`，带轻微圆角与边框），点击图片弹出轻量居中大图预览层（支持滚轮/点击关闭、`Esc` 退出）。
5. **日期双链（`[[YYYY-MM-DD]]`）**：
   - **自动补全**：键入 `[[` 后弹出轻量浮层，默认列出「昨天 / 今天 / 明天」及最近写过笔记的 10 个日期，支持继续输入数字（如 `11-2`）过滤，选中后插入标准日期双链节点。
   - **渲染与跳转**：呈现为行内胶囊标签（如 `📅 2026-11-24`；若目标日期已有笔记则显示实心图标，未创建则显示虚线样式）；**点击直接跳转**至该日期，并将当前日期压入返回栈以便一键 `[←]` 返回。
6. **WYSIWYG ↔ Markdown 源码模式切换**：
   - 顶栏点击 `</>` 或按 `⌘/`（`Ctrl+/`）切换：
     - 切到**源码模式**：先将当前编辑器状态序列化为规范 Markdown（带光标附近位置尽量保持），渲染等宽字体文本编辑区，直接编辑 Markdown 文本同样触发自动防抖保存与 `#tag`/`[[date]]` 索引刷新。
     - 切回**所见即所得模式**：将源码重新解析为 Tiptap 文档树并渲染。

### 4.5 行内标签 `#tag` 交互
- 正文输入 `#工作` 或 `#bug-fix` 后（空格/标点结束），自动识别为可视化标签高亮样式（不破坏纯文本输入流畅度；在代码块和行内代码中不触发）。
- 点击正文中的任意 `#tag` 高亮词，打开搜索面板并自动以该标签作为过滤条件展示所有相关日期笔记。

## 5. AI 协同交互与并发冲突处理

### 5.1 侧边栏轻量 AI 入口
1. **顶栏「AI 总结今日」按钮（`✨`）**：
   - 点击前若当前笔记有未防抖落盘的更改，先立即完成一次强制保存（保证 Agent 读到最新内容）。
   - 调用 `window.sidecar.agent.sendMessage(...)` 向当前 Antigravity 对话发送结构化提示词（例如：`请调用 daily-notes 工具读取我今天 (YYYY-MM-DD) 的笔记与待办，帮我提炼今日工作总结、未完成项与明日建议。`）。
   - 若用户尚未开启对话或宿主不支持 `sendMessage`（如独立浏览器调试模式），降级为将提示词复制进剪贴板并弹出轻提示「已复制总结指令，请粘贴到对话中执行」。
2. **Bubble Menu「发送到对话」**：
   - 选中文字点击「发送到对话」，向当前对话发送带日期与项目上下文的引用内容（例如：`关于我在 2026-11-25 每日笔记中的这段记录：\n> ...\n请帮我...`），并在面板顶部轻提示「已发送到对话」。

### 5.2 Agent 写入后的实时同步与冲突解决
由于 Sidecar UI 与 MCP Server 分别在不同进程中访问同一个 SQLite 数据库，客户端通过「轻量轮询（每 `2s` 请求一次 `GET /api/notes/:date/meta`，面板失焦时暂停，聚焦恢复时立即拉取一次）」感知 Agent 的写入：

| 当前侧边栏编辑器状态 | 检测到服务端 `revision > localRevision` 且 `last_editor === 'agent'` |
| :--- | :--- |
| **无未保存本地修改（Clean）** | 静默拉取最新笔记无缝更新编辑器内容，同时在底栏/顶部轻提示：`✨ Agent 已更新此笔记 [查看改动/对比] [一键撤销]`（保留 15s 或直到下次编辑） |
| **有未保存本地修改（Dirty）** | **绝不直接覆盖用户输入！** 立即停止自动覆盖保存，在顶部弹出醒目但不阻断阅读的冲突处理条：`⚠️ Agent 刚刚更新了本篇笔记，而你有未保存编辑` → 提供三个按钮：`[保留我的并覆盖]` / `[放弃我的并加载 Agent 版本]` / `[查看 Agent 版本并复制合并]` |

### 5.3 历史快照查看与一键撤销
- 每次 Agent 通过 MCP 修改笔记（或用户点击「加载 Agent 版本」覆盖本地内容、或用户回滚版本）时，系统自动在 `note_revisions` 中存档修改前完整正文。
- 点击提示条中的「一键撤销」或通过 `···` 菜单打开「历史快照」列表抽屉，可按时间倒序查看每次保存/AI 写入记录（标注来源 `Agent` / `手动回滚前备份` / `自动快照` 及时间），预览正文差异后一键恢复为当前内容。

## 6. 键盘快捷键与可访问性

### 6.1 全局与编辑器快捷键

| 快捷键（macOS / Linux） | 作用域 | 动作 |
| :--- | :--- | :--- |
| `⌘K` / `Ctrl+K` | 面板内全局 | 打开 / 关闭全文搜索与筛选面板 |
| `⌘/` / `Ctrl+/` | 面板内全局 | 切换所见即所得 ↔ Markdown 源码模式 |
| `⌘S` / `Ctrl+S` | 面板内全局 | 立即强制保存当前笔记（跳过防抖延迟，提示「已保存」） |
| `Alt+←` / `Alt+→` | 面板内全局 | 日期后退（双链返回栈） / 前一天后一天快捷切换 |
| `⌘B` / `⌘I` / `⌘Shift+X` | WYSIWYG 编辑器 | 加粗 / 斜体 / 删除线 |
| `⌘E` / `Ctrl+E` | WYSIWYG 编辑器 | 行内代码 |
| `⌘Shift+9` / `⌘Shift+7` / `⌘Shift+8` | WYSIWYG 编辑器 | 任务清单 / 有序列表 / 无序列表 |
| `⌘V` | 编辑器内 | 粘贴图片自动上传本地 `attachments/` 并插入；粘贴 URL 自动包为链接（若当前有选中文字） |

### 6.2 可访问性与测试标识（`data-testid`）
