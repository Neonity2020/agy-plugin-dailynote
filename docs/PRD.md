# Daily Notes（每日笔记）产品需求文档（PRD）

## 1. 产品概述

### 1.1 背景与痛点
在日常使用 Antigravity 进行编码、排障与方案讨论时，开发者频繁需要在任务间隙记录零散灵感、当天待办、踩坑记录和 AI 对话结论：
- 切换到外部笔记软件会打断开发心流，且外部笔记无法直接感知当前工作区上下文或与 Antigravity Agent 互动。
- 在聊天历史中翻找“前天讨论的接口约定”或“昨天没做完的排查项”成本极高。
- 纯文本/纯源码 Markdown 编辑在窄侧边栏中可读性差，而传统文件夹树笔记工具在侧边栏场景下又显得过重。

### 1.2 产品定位
**Daily Notes（每日笔记）** 是一款运行于 Antigravity 辅助侧边栏（Auxiliary Side Pane）的轻量化、所见即所得（WYSIWYG）每日笔记插件：
- **即开即写**：打开侧边栏直接定位到「今天」，无需先起文件名或建目录。
- **富文本直观，源码可控**：日常书写享受类似 Typora / Notion 的即时排版体验，需要精确微调或整篇复制时可一键切回 Markdown 源码视图。
- **本地私有优先**：全部文本与版本快照存储在用户本机的 SQLite 数据库，图片附件落在同级目录，离线可用、零云端依赖。
- **AI 原生协同**：Antigravity Agent 可通过插件内置的 MCP 工具按需查询历史笔记、汇总未完成待办、整理会议/调试纪要并写入当日笔记，且每次 AI 写入均留有可一键撤销的历史快照。

## 2. 核心作用域与信息架构

### 2.1 插件身份
- **展示名称**：`Daily Notes`（中文界面标题：`每日笔记`）
- **插件标识（`name` / slug）**：`daily-notes`
- **源码仓库**：基于 `agy-plugin-dailynote` 仓库作为独立 Antigravity 插件开发与发布。

### 2.2 全局按日期共享模型
- **按日唯一**：以用户本机当前时区的自然日 `YYYY-MM-DD` 为唯一主键，每天对应 1 篇整页自由文档（跨所有工作区/项目共享，保证工程师每天的工作流与思考记录在一处收口）。
- **轻量标签索引**：正文任意位置自然输入的 `#标签`（如 `#perf`、`#发布前检查`）会被自动提取并建索引，支持按标签筛选与搜索。
- **可选项目关联**：默认不强绑定项目；当用户处于某个工作区时，顶部提供一键「关联当前项目」操作，将该日笔记与当前 Workspace URI/名称建立多对多关联，便于后续按项目过滤回顾（同一天可关联多个项目，例如上午排查 A 项目、下午开发 B 项目）。

## 3. 核心用户故事与典型场景

| 编号 | 角色 | 场景与诉求 | 预期结果 |
| :--- | :--- | :--- | :--- |
| **US-01** | 开发者 | 在写代码时突然想到一个边界 Case，希望 1 秒内记录下来 | 打开侧边栏「每日笔记」，默认落在今天，直接输入内容并自动防抖保存，支持输入 `- [ ]` 立刻变成可点击复选框 |
| **US-02** | 开发者 | 新的一天开始工作，想把昨天没做完的待办接着做 | 打开今天空白笔记时，若最近一个有待办的过往日期存在未完成 `- [ ]` 项，顶部出现「昨日有 N 项未完成待办 · 一键顺延到今天」提示条，点击即可幂等追加到今日笔记 |
| **US-03** | 开发者 | 想快速定位上周提到的某个报错关键词或某天的记录 | 点击顶部日期标题展开迷你日历（有圆点标记写过笔记的日期）快速跳转；或打开搜索框输入中英文关键词、`#标签`、项目名，查看命中片段并一键跳转 |
| **US-04** | 开发者 | 在笔记中引用前一天的设计决定，希望点击即可溯源 | 输入 `[[2026-11-24]]` 形成日期双链胶囊，点击直接跳转到对应日期，且顶部支持返回上一浏览日期 |
| **US-05** | 开发者 | 需要把一段调试日志、截图或对比表格放进今日笔记 | 粘贴/拖拽图片直接本地保存并预览；输入 `/` 或 Markdown 语法插入高亮代码块与表格 |
| **US-06** | 开发者 | 让 Antigravity Agent 总结今天的工作或记录一条调研结论 | 在聊天中运行 `/daily-summary` 或自然语言要求 Agent 记录结论，或在侧边栏点「AI 总结今日」；Agent 通过 MCP 安全写入当日笔记，侧边栏自动刷新并提示「Agent 已更新 · 一键撤销」 |
| **US-07** | 开发者 | 在写某段复杂架构思考时想请 AI 帮忙评估 | 选中笔记中的任意段落，在悬浮工具栏点击「发送到对话」，内容自动带上日期上下文发送至当前 Antigravity 对话 |
| **US-08** | 开发者 | 需要把今天的日报发到团队群或存档成 `.md` 文件 | 点击右上角菜单「复制 Markdown」或「导出 `.md`」，立即得到标准 GFM 格式文本或 `YYYY-MM-DD.md` 文件 |

| :--- | :---: | :--- |
| **即时 Markdown 快捷语法** | P0 | 输入 `# `、`## `、`### `、`- `、`1. `、`> `、`---`、`` `code` ``、`**bold**`、`*italic*`、`~~del~~` 等实时转换为富文本块/行内样式 |
| **选中悬浮工具栏（Bubble Menu）** | P0 | 选中文本后就近弹出紧凑工具栏：加粗、斜体、删除线、行内代码、高亮、超链接、以及「发送到对话」 |
| **斜杠插入菜单（`/` Command）** | P0 | 在空行或段首输入 `/` 唤起可键盘上下筛选的块插入菜单（标题 H1–H3、任务清单、无序/有序列表、代码块、引用、表格、分割线、图片、日期双链） |
| **任务清单（Task List）** | P0 | 支持 `- [ ]` / `- [x]` 快捷语法与点击复选框切换完成态；自动统计当日已完成/总待办数 |
| **代码块与行内代码** | P0 | 支持 ```` ```lang ```` 语法高亮代码块（常见前后端/Shell/SQL/JSON/YAML 语言识别与切换）及一键复制代码块 |
| **表格编辑** | P0 | 支持插入表格、单元格内换行与编辑、增删行列、窄侧边栏下表格容器横向滚动不撑破布局 |
| **图片粘贴与拖拽** | P0 | 支持剪贴板粘贴截图（`Cmd+V`）与文件拖拽插入；保存至本地 `attachments/` 目录并渲染缩略预览；点击支持轻量放大查看 |
| **日期双链（`[[YYYY-MM-DD]]`）** | P0 | 支持键入 `[[` 触发最近日期/有笔记日期补全，或输入标准 `[[YYYY-MM-DD]]` 渲染为可点击跳转标签；支持反向关联提示或返回栈 |

### 4.2 每日笔记生命周期与导航（P0）

| 需求项 | 优先级 | 详细描述 |
| :--- | :---: | :--- |
| **默认落点与惰性创建** | P0 | 打开侧边栏默认定位本机当前自然日；未输入实质内容前仅展示空白编辑区，不向 SQLite 插入冗余空记录 |
| **自动防抖保存** | P0 | 编辑停止 400ms–600ms 后自动落盘至 SQLite，切换日期、切源码模式或窗口失焦时立即刷盘，保证不丢字 |
| **跨零点提醒** | P1 | 当用户一直停留在昨日视图跨过本机零点时，顶部出现温和提示条「新的一天已开始 · 切换到今天」，不强行打断当前输入 |
| **昨日待办一键顺延** | P0 | 今日笔记尚无内容且未关闭提示时，若最近一篇前序笔记存在未完成 `- [ ]` 任务，展示轻提示条；点击「一键顺延」将未完成任务幂等拷贝至今日顶部任务区 |
| **日期切换与迷你日历** | P0 | 顶部支持「前一天 / 后一天 / 回到今天」；点击日期标题展开/收起紧凑月历面板，清晰标出「今日」与「已有笔记的日期圆点」 |
| **全文与多维检索** | P0 | 支持中英文关键词全文检索（FTS5 `trigram` + 1–2 字子串降级匹配），可叠加 `#标签` 胶囊或关联项目筛选，结果列表展示日期、标题摘要与高亮命中片段 |
| **标签与项目关联** | P1 | 从正文中自动抽取 `#标签` 入库（排除代码块与 URL 锚点）；顶部提供一键「关联当前项目 / 取消关联」胶囊按钮 |

## 5. V1 显式非目标（V2 Backlog）

以下功能经对齐确认**不纳入 V1 范围**，将在后续版本按需规划：
- **自定义每日模板系统**：V1 仅保持空白页 + 昨日未完成待办一键顺延，不做模板管理器与变量占位符引擎。
- **全量打包导出 / `.db` 文件下载**：V1 仅提供单日 `.md` 导出与复制；全量日期导出 ZIP 包与数据库一键导出留待 V2。
- **外部 Markdown 文件夹导入**：批量扫描导入历史 `YYYY-MM-DD.md` 文件留待 V2。
- **云端同步与多人协作**：不引入账号体系、端到端云同步或实时多人协同编辑（用户可通过云盘同步 `~/.gemini/daily-notes/` 目录作为临时备份手段，需注意关闭多端并发写入）。
- **自定义页面 / 任意目录树文档**：本插件专注「按日记录」心智模型，不演变为通用多层级知识库（不建文件夹树、不建无日期孤立页面）。
- **独立系统级全局快捷键 / 桌面浮窗**：V1 完全寄生于 Antigravity 辅助侧边栏及 CLI/对话环境。

## 6. V1 验收标准（Acceptance Criteria）

1. **插件规范与加载**：执行 `agy plugin validate --strict` 零错误通过；启用插件后，Antigravity 辅助侧边栏正确出现「每日笔记」视图，暗/亮色主题切换时面板配色即时跟随。
2. **编辑器完备性**：在 360px 宽度侧边栏中，所有 6 项扩展块（任务清单、高亮代码块、表格、图片粘贴/拖拽、日期双链跳转、源码视图切换）均无布局错位或数据丢失；WYSIWYG ↔ 源码来回切换 5 次内容保持语义等价。
3. **本地持久化与检索**：重启 Antigravity 后当日笔记、标签、关联项目及粘贴图片完整保留在 `~/.gemini/daily-notes/`；中英文 1–2 字（如 `笔记`）及 3 字以上关键词（如 `每日笔记`、`SQLite`）均可毫秒级检索命中。
4. **AI 双向协同与安全回滚**：
   - 在对话中调用 `/daily-capture` 或自然语言要求追加内容，侧边栏在 2 秒内自动刷新显示新内容，且底部/顶部弹出「一键撤销」入口；点击撤销后完全恢复至 AI 写入前版本。
   - 若用户侧边栏存在未保存改动且版本落后，Agent 尝试整篇更新时被乐观锁拒绝并收到明确冲突提示，用户手写内容不被静默覆盖。
5. **待办顺延幂等性**：连续两次触发昨日未完成待办顺延（或在同日重复调用接口），不会产生重复任务行。
6. **单日导出可用性**：导出的 `YYYY-MM-DD.md` 在通用 Markdown 阅读器中格式正确，标题、任务清单、代码块、表格与双链保留完整。
